# Сообщить об уязвимости

Обратитесь через контакты на https://24projects.ru/.
Не публикуйте токены, ключи приглашений, содержимое чужих разговоров или
персональные данные в GitHub Issues. Для описания достаточно шагов
воспроизведения на собственной тестовой комнате и версии проекта.

Проверки выполняйте только на принадлежащих вам экземплярах сервиса.
