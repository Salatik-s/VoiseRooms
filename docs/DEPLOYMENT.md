# Развёртывание автором

Для выпуска 1.2.0 с пользовательскими APK и IPA используйте [обновление через deploy/update.ps1](UPDATING-1.2.0.md). Ниже сохранено описание первоначального установщика.

Целевой адрес: **https://voise.24projects.ru/**, Ubuntu-хост **157.228.191.231**.
Существующие сайты обслуживает Nginx. Скрипт добавляет отдельный virtual host и
сертификат Let's Encrypt; второй сервер на портах 80/443 не устанавливается.

## С компьютера автора

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File 'C:\Users\andre\Desktop\voicerooms\deploy\send-to-host.ps1' `
  -AgreeLetsEncryptTerms
```

`-AgreeLetsEncryptTerms` разрешает создание ACME-аккаунта с условиями Let's
Encrypt, если существующего аккаунта на хосте недостаточно. Email аккаунта
берётся из приватного поля `LE_ACCOUNT_EMAIL` или параметра `-Email`.
На компьютере автора поле уже заполнено. OpenSSH запросит пароль root; скрипт не хранит его.

Вариант без добавления карточки портфолио: добавьте `-SkipPortfolio`.

Скрипт берёт **закоммиченную** версию исходников, проверяет точный репозиторий и
создаёт публичный ZIP через `git archive`. Приватный файл находится отдельно:
`%USERPROFILE%\.codex\private\voicerooms\production.env`. Он генерируется из уже
имеющейся конфигурации VoiceRooms; чужие токены в него не копируются. Новые
служебные ключи сохраняются и не меняются при каждом запуске.

## Что проверяет и меняет скрипт

1. Проверяет IPv4 хоста, A/AAAA домена, локальный Docker, память, swap, диск и
   владельцев необходимых портов. На хосте должно быть не менее 1 ГиБ свободного
   swap для последовательной сборки.
2. Передаёт публичный архив и приватный env раздельно; проверяет SHA-256.
   Отказывает при небезопасных путях, символических ссылках или приватных файлах
   внутри архива.
3. Создаёт отдельный Compose-проект `voicerooms` и собственные тома. Выполняет
   миграции, последовательно собирает образы и проверяет реальную готовность
   PostgreSQL и API LiveKit.
4. Настраивает только `voise.24projects.ru`, проверяет Nginx до reload, получает
   сертификат и проверяет HTTPS без отключения проверки сертификата. Через
   публичный адрес создаёт временную комнату, проверяет отказ без ключа,
   получение медиатокена с ключом и закрытие комнаты.
   Каталоги HTTP-01 получают права `755`, публичный пробный файл — `644`;
   перед обращением к Let's Encrypt проверяется чтение через Nginx и HTTP-домен.
   Приватные env и ключи при этом остаются закрытыми.
5. Проверяет Telegram `getMe`. При наличии существующего VPN сервиса
   `24projects-vpn-1` использует его через отдельное подключение к сети;
   конфигурация и подписка VPN не изменяются. Другой polling-процесс этого же
   бота необходимо остановить: Telegram не допускает двух poller одновременно.
   `getMe` выполняет основной процесс бота. Установщик читает свежие сообщения
   его запуска и состояние контейнера, не запуская второй aiogram в том же
   лимите памяти. Для бота установлены пределы 192 МиБ RAM и 384 МиБ RAM+swap.
6. После успешных проверок добавляет личный проект Андрея в существующее
   портфолио. Только на время атомарного обновления `site.json` контейнер
   портфолио кратко останавливается; исходный файл сохраняется в `backups`.
   При повторном запуске карточка не дублируется и не перезаписывает правки.

Публикация не добавляет соавторов, не меняет профили участниц и не заменяет
первый экран портфолио. Карточка появляется в каталоге и в проектах Андрея.

## Порты

| Порт | Доступ | Назначение |
| --- | --- | --- |
| 80, 443/TCP | Интернет, существующий Nginx | HTTPS и ACME |
| 7881/TCP | Интернет | WebRTC TCP fallback |
| 50300–50350/UDP | Интернет | WebRTC media |
| 7880, 3099, 5199/TCP | Только loopback хоста | Media API, backend, frontend |
| 5432/TCP | Только Docker-сеть | PostgreSQL |

Если firewall провайдера фильтрует трафик, эти медиапорты нужно разрешить в панели
хостинга. Для сетей, запрещающих такой WebRTC-трафик, нужен TURN. Базовая
конфигурация не обещает работу во всех корпоративных сетях.

## Диагностика после установки

```bash
cd /opt/voicerooms/current
docker compose --env-file /etc/voicerooms/production.env ps
curl --fail https://voise.24projects.ru/api/ready
```

При автоматически подключённом существующем VPN добавьте к Compose-командам
`-f compose.yaml -f proxy.compose.yaml`. Не запускайте `docker compose down -v`:
флаг `-v` удаляет данные. Закрытый код владельца не является идентификатором
Telegram; для управления используется команда `/admin` в личном чате с ботом.

Скрипт подготовлен и проверен локально; запуск на реальном хосте выполняет автор.
После него необходима проверка звонка с двух устройств через внешний Интернет.
