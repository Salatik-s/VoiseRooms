# Проверка версии от 2 ноября 2026 года

Проверялся только VoiceRooms. Остальные работающие проекты не обновлялись.

- Изолированный PostgreSQL 16 на loopback, отдельная тестовая база.
- Начальная миграция успешно применена к ещё одной пустой тестовой базе;
  повторная проверка Prisma подтвердила актуальную схему.
- Настоящий LiveKit 1.13.11 с отдельными случайными ключами.
- Проверка Telegram `getMe`: токен отвечает, имя `vidagram_bot`, inline включён.
- 22 интеграционные проверки API: реальные PostgreSQL и API LiveKit. В том числе
  отказ поддельным правам, одноразовый обмен, срок комнаты, закрытие, подпись роли
  владельца, запрет повторного токена, права на файлы, AES-GCM и срок файла.
- Тесты подписи сессий и Telegram initData, тесты inline-кэша и обработки ошибок
  бота, проверки добавления единственного автора без изменения других записей.
- Две браузерные вкладки реально подключились: микрофон публиковался с GCM,
  модерация отключила публикацию второго участника, разрешение не включило его
  микрофон принудительно, имя обновилось у обоих, зашифрованный чат доставился.
- Передачу экрана подтвердил владелец во время локальной проверки.
- Прежнее оформление главной страницы восстановлено по просьбе владельца.
- Финальная сборка TypeScript/Vite прошла. Проверены локальные HTTP-маршруты
  сайта, готовности API и отдельного демо портфолио с единственным автором Андреем.
- Новая серверная проверка ключа приглашения добавлена после браузерного
  прогона: отдельно проверены отказ без подтверждения и совпадение протокола
  между JavaScript, Python и Kotlin.
- Docker Compose разобрал итоговую конфигурацию; бинарник LiveKit принял
  сгенерированный YAML. Docker Engine на компьютере отсутствует, поэтому
  сборка Linux-контейнеров и полное развёртывание проверяются на хосте.

Ограничения: нет нагрузочного прогона на 150 пользователей, проверки всех iPhone
и Android-моделей или независимого аудита криптографии. Telegram polling локально
не запускался, чтобы не конфликтовать с прежним экземпляром бота. Локальная
проверка не подтверждает внешние firewall, HTTPS и ICE-маршрут нового хоста:
это проверяется после его фактического развёртывания.
